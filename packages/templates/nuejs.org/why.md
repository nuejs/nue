# Spin world-class sites without a design team
Think about the sites you admire. Apple. Linear. Stripe. Behind each one sits a team of designers and engineers working to maintain that level of polish. Years of iteration. Millions in payroll.

**A global design system changes the equation.**

You build this system once and every new project inherits it: layout, design, interactivty, and motion. No designer-developer handoff. No Figma-to-React translation.

90% of the work is done before you start. The rest is what makes each site unique.




## Who is this for?

**Agencies** - Build one world-class system, deploy to all clients.

**Businesses** - Get Apple-level design without the Apple-sized team.

**Content marketers** - Push AI-assisted content to multiple domains.

**Documentation teams** - Scale technical content without sacrificing quality.

**CSS developers** - Build a global design system and scale your expertise.

**Solo developers** - Use one shared system for all your work.


## Get strated
The framework is production-ready. You can create your first multi-site setup now.

**CSS professionals:** Use `nue create multi-site` to get a working foundation. Build your global design system on top of it.
